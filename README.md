# TemplateLinkedList
Этот проект представляет собой реализацию односвязного списка (Linked List) на C++ с шаблонами, поддерживающую различные операции и алгоритмы обработки данных.

## Разберемся подробнее:
### 1. Структура Node
```cpp
template<typename T>
struct Node {
    T data;
    Node* next;

    explicit Node(const T& value = T(), Node* nex = nullptr): data(value), next(nex) {}
};
```
Это вспомогательная структура, при помощи которой мы создаем узел в списке. Узел состоит из хранимой информации и указателе на следующий узел. Так же здесь конструктор по умолчанию, в котором у нас изначально указатель указывает на конец списка, а хранимое значание пустое.
Explicit - предотвращает неявные преобразования.
